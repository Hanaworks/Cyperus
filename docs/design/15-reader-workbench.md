## 交互与范围

- 按2026-11-06用户最新截图，顶部改为30 px单行，图标及文件 / 查看 / 帮助菜单在左、活动文档 / 应用标题居中、真实窗口按钮在右；覆盖此前双行顶部。下拉菜单直角、26 px行高。无顶部搜索；查看菜单搜索及Ctrl+F继续打开左侧正文搜索。标题与留白保留原生拖动标记，菜单/按钮不参与拖动；人工验收边界见执行记录。
- 最左活动栏宽48 px，按钮48×48 px、图标24 px，外边距0。文件、搜索、大纲同级，再次点击收起侧栏。不保留左下管理齿轮入口。
- 侧栏默认240 px，键盘、拖动与窗口缩小时共用180–min(480,窗口宽−340)限制。资源管理器标题35 px、左20右8 px，分组/编辑器/树行22 px、缩进16 px；列表复用标签会话。按需列举，非支持文件置灰。
- 阅读区顶部为35 px连续直角多标签，下方直接接正文，文档路径移至底部：多选或拖入多个文件均打开；同一路径去重，切换缓存文档不重新解析，各自保留阅读位置。支持关闭、中键关闭、Ctrl+W、Ctrl+Tab、Ctrl+1..9。
- 文件树点击 Markdown 进入标签阅读；目录展开状态在侧栏切换时保留。更换根目录不关闭已打开标签。
- 搜索作用于当前文档正文，提供匹配数、上一条、下一条和高亮；大纲随当前标签变化，点击定位章节。
- 2026-11-07：每标签独立保存搜索词和匹配序号，切换/重开搜索只恢复高亮，不覆盖阅读位置。文件菜单或Ctrl+Shift+T可恢复最多15条最近关闭的路径文档，回到原标签顺序及阅读/搜索状态；只在当前会话有效，文件消失时提示且不留新空标签。
- 正文为平面预览，按 [2026-11-06设计基线](./16-ui-design-draft.md) 采用15/24 px、左右26 px/上16 px，窄窗适当收紧；界面与正文默认浅色，以白色和紫色为主。底部状态栏22 px。空状态、加载、目录与文件失败可读，失败不清空其他标签。
- 22 px底部状态栏统一路径、编码、章节数、文档数量与加载状态，常驻界面 / 正文主题切换，保持主题独立与纸张主题。环境信息通过底部按钮或帮助菜单打开底部浮层，不在顶部常驻显示。
- 长路径优先保留文件名，环境入口位于底部最左。搜索重入全选关键词、Escape回阅读容器；大纲区分未打开文档与无标题。关闭活动或含焦点的被关闭项后归还活动标签，最后关闭回开始页打开入口。
- 当前历史版边距基线：深灰活动栏/浅灰侧栏/白色内容/紫色整条底栏连续直角拼接，面板外边距0、侧栏1 px分隔，文章无卡片表面。正文上16/左右26/下28 px，普通块间距16 px，内部留白按设计16统一；底栏12 px白字与独立焦点。
- Git 为后续增强：仓库状态、变更列表、差异查看；提交与同步范围待定。本轮不显示无效 Git 按钮。

## 实现方式

沿用 Tauri + Vue 与现有 Worker，保留单个活动阅读 DOM，序列化 ParseResult 缓存在文档会话中。引入框架无关的多文档会话控制器，视图通过更新回调刷新；不把每份文档长期挂在 DOM。文件夹枚举由独立宿主 registry 校验根目录与子路径，只授权枚举，不扩大 asset scope；图片仍逐文件授权。原生选择器支持多选与文件夹，无新依赖。

选择现有渲染架构上的工作台布局；独立窗口不满足侧栏连续切换，完整编辑器功能超出当前阅读需求。本轮不引入编辑、目录写入、Git 操作、安装依赖、分支或提交。

## 验收

1. 从文件树打开两个不同文档，两个标签均存在；切换不增加解析次数，目录、大纲和阅读位置分别正确。
2. 根目录 / 子目录按需列举；越界与链接路径被拒绝，枚举不授予资源读取权限。
3. 多文件选择、拖入、启动参数均处理全部 Markdown；重复打开不产生重复标签。
4. 关闭活动 / 非活动 / 最后一个标签正确；慢请求不能覆盖新激活标签，关闭不能留宿主句柄。
5. 文件 / 搜索 / 大纲切换、侧栏收起与调宽、搜索下一条和快捷键可用，保留既有主题和安全回归。
6. 前端与宿主测试、浏览器端到端、release 构建和原生功能复验。原性能数据保留，本轮不重跑性能矩阵。
