- T11 先接最小 Worker 调用及 HTML 消毒，否则无法安全、响应流畅地验证阅读；正式队列、预算和完整安全策略仍归 T23–T25。

- 基准入口 `window.__M0__` 仅开发或显式基准构建启用；正常发行界面不暴露测量按钮。
- 原生验证报告只在显式 `--m0-report=...` 启动时启用，并限制写入仓库 benchmarks 目录。
- 用户明确取消 T14，本轮技术决策不得声称 Web 已在性能上胜过 Qt；M0 门槛按这项范围调整记录。
