## 用户决定与授权范围

- 用户经讨论确认 VS Code 式布局，并明确要求“继续推进”：文件 / 搜索 / 大纲同级活动栏、可伸缩侧栏、真实只读文件树、基本多标签与各自阅读位置。
- 本轮授权覆盖上述 UX 实现、现有文档同步、测试、构建与本地运行验证；在当前 `D:\Project\Markdown` 工作目录保留既有改动，不创建隔离 worktree。
- 不安装依赖或 Qt，不改系统配置，不进行 Git 分支、提交、推送等写操作；本轮不扩展到编辑或目录写入。
- 用户当前优先 UX，性能专项后置；保留 [M0 执行记录](./m0-progress.md)、[原测量结果](../../benchmarks/results.csv) 与 [原测试结论](../../benchmarks/findings.md)。大文档交互与空闲 CPU 未达标仍有效，不把功能改进写成性能达标。
- Git 仅后续规划仓库状态、变更列表和差异查看；提交 / 同步范围待定。当前没有已实现的 Git 功能，不显示无效入口。
