## 验收口径

- 前端测试验证实际会话和 DOM；浏览器中的文件与系统边界使用 mock。Rust 测试覆盖真实临时文件、目录监听、路径约束及 Windows 命名管道。
- 原生探针仅在显式 `--m1-profile` 且配置目录位于仓库 benchmarks 内启用，不使用用户日常配置。报告 `complete` 只代表探针结束，必须另外检查 errors、进程退出码及各项指标。
- `firstReadableMs` 从前端发起打开到阅读视图就绪，包含宿主读文件、IPC、Worker 和首次 DOM；不包含进程 / WebView 创建。`coldProcessToFirstReadableMs` 单独从启动进程计时。
- `fullRenderMs` 必须完成全部段遍历及图表终态；不同于仅首屏就绪，也不要求全部 DOM 同时驻留。图表统计累计稳定图 ID，不只数最后可见段。
- RSS 为目标进程树 Working Set 求和，共享页可能重复；采样可能漏掉短峰，不等于精确 OS 峰值。48 MiB 配额仅为保留的序列化 HTML UTF-8 字节，不是整个进程内存承诺。
- 暂不将 ADR-003 的 Proposed 目标改成已批准或放宽。未通过、未测、需要用户安装授权的项目保留。

## 本轮修复的集成缺陷

1. 初次读取前后文件由 UTF-8 变成 UTF-16 / GB18030：稳定元数据与原始字节成对核对，再解码。
2. 旧搜索 / 锚点请求完成后覆盖新导航：在异步读取前后以及 DOM 修改前检查请求代次。
3. Tauri 正常关闭回调最终使用 destroy，缺少窗口权限导致保存后未退出：仅为主窗口补齐对应能力。
4. 次实例连接后不发送完整请求可阻塞其他启动：活跃连接有绝对期限，提前断开后监听恢复；空闲监听使用事件等待。
5. 分段占位区快速滚动、回到顶部立即换标签：不能保存前一驻留块的伪锚点，也不能保留旧阅读锚点。
6. 全文遍历统计不能只数最后驻留的图表；原生关闭、idle 和位置检查也不能只相信报告完成标志或会话元数据。

## 三轮固定发布版性能

[原始 12 组运行索引](../../benchmarks/m1-release-measurements.json)、[24 行冷 / 暖 CSV](../../benchmarks/m1-release-results.csv)、[环境与夹具哈希](../../benchmarks/m1-release-environment.json) 均保留；每组有独立 profile、报告和 active.csv，100 KB 的三组另有完整 60 秒 idle.csv。Windows 10.0.26300、WebView2 156.0.4314.58，同一 EXE SHA256。

每个大小每轮启动新进程 / 配置，先首次打开再关闭重开；未清理 OS 文件缓存，所以“冷”不代表磁盘冷缓存。下表为三轮范围（完整渲染 / P95 包含冷暖共六次），并非统计显著性结论。

| 夹具 | 进程启动至首屏 ms | 首次打开 / 重开可读 ms | 全文遍历完成 ms | scroll→rAF P95 ms | 流程 RSS 采样峰 MiB |
|---|---:|---:|---:|---:|---:|
| 100 KB | 1533–1564 | 358–383 / 45–58 | 82–419 | 18.9–21.2 | 594.5–601.5 |
| 1 MB | 1677–1751 | 544–567 / 170–183 | 192–592 | 20.9–29.7 | 711.7–745.1 |
| 10 MB | 2453–2630 | 1465–1592 / 950–1006 | 7330–8420 | 18.7–21.2 | 1079.9–1100.8 |
| 50 MB | 7211–7513 | 6059–6336 / 5609–5887 | 31526–32732 | 40.0–47.8 | 2525.5–2636.4 |

结论：本组 scroll→rAF P95 通过暂定值；它不是键盘输入 / 标签切换 P95。首次打开、冷进程启动、RSS 和部分全文渲染目标仍未通过；50 MB 的可读性 / 分段正确性不等于性能承诺。RSS 峰覆盖一组冷开、重开、全文遍历和末尾普通文档，不是某一瞬间首屏的独立峰。空闲三轮均超过 100 ms 目标。继续保留原阈值，不据此宣布完整 M1 性能验收通过。
