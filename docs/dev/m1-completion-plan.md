## Review Focus

- 编码 BOM / 二进制 / 短中文误判，保持原始字节 IPC 契约。
- 同时启动两个进程、主窗口尚未就绪、不同工作目录参数、关闭再启动恢复。
- 缓存逐出期间文件更新 / 关闭，活动标签和轻量阅读状态不可丢失。
- 分段遇到长表格、列表、脚注与无标题文档；搜索 / 锚点不得只覆盖可见部分。
- 窗口已离开显示器、损坏状态与写入失败，不得导致窗口不可见或阻止正常阅读。
